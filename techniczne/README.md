# Dokumentacja techniczna projektu

Ten katalog zawiera materiały robocze i techniczne związane z utrzymaniem repozytorium i przygotowaniem publicznego przewodnika. Nie jest częścią treści publikowanej w GitHub Pages.

## Struktura

- `audyty/` — raporty z audytów i kontroli jakości;
- `proces/` — plany, checklisty i procedury pracy;
- `mapy/` — manifesty źródeł danych, specyfikacje wdrożonych map, generatory i instrukcje odtwarzania;
- `wizualizacje/` — zasady, stan wdrożenia i plan rozwoju zdjęć oraz innych materiałów wizualnych w przewodniku.

Materiały merytoryczne dla uczestników wyjazdu pozostają w głównych plikach tematycznych repozytorium.

## Bieżące analizy

- [Audyt i plan przebudowy materiałów o wycieczkach](audyty/AUDYT-PRZEBUDOWY-STRONY-WYCIECZKI.md) — wyniki audytu, rekomendowany podział materiału, zasady dostępnych tabel i plan jednego całościowego wdrożenia; przebudowa nie została jeszcze rozpoczęta.
- [Audyt szerokości treści i nagłówków](audyty/AUDYT-SZEROKOSCI-TRESCI.md) — zmiana wdrożona i sprawdzona na komputerze; pozostaje ręczna kontrola na urządzeniu mobilnym i przy powiększeniu.
