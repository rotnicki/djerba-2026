# Djerba 2026

Prywatna baza ustaleń dotyczących wyjazdu na Dżerbę w 2026 roku.

Repozytorium służy jako trwałe źródło ustaleń. Bieżące analizy i rozmowy mogą powstawać w projekcie ChatGPT, a najważniejsze wnioski powinny być przenoszone tutaj.

## Zasady

- Nie zapisujemy danych wrażliwych, numerów dokumentów ani danych uczestników, jeśli nie jest to konieczne.
- Informacje zależne od czasu, takie jak ceny, taryfy i dostępność, oznaczamy datą sprawdzenia.
- Ustalenia potwierdzone zapisujemy oddzielnie od pomysłów i rzeczy do weryfikacji.
